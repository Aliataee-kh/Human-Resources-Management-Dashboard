# 📊 داشبورد مدیریت منابع انسانی — Power BI

داشبورد تحلیلی منابع انسانی طراحی‌شده درپاور بی ای برای بررسی وضعیت پرسنل، حقوق و دستمزد، عملکرد و پراکندگی جغرافیایی نیروی انسانی.

## 📌 داده‌های مورد استفاده

سه فایل اکسل به‌عنوان منبع داده استفاده شده است:

* **اطلاعات پرسنلی:** مشخصات فردی، تحصیلات، سمت، استخدام و محل سکونت — 1,062 رکورد
* **حقوق و دستمزد:** حقوق ناخالص ماهانه — 10,611 رکورد
* **امتیاز عملکرد:** امتیاز ماهانه کارکنان — 10,611 رکورد

## 🛠️ ابزارها و تکنیک‌ها


* Power BI Desktop (مدل‌سازی داده، DAX، Power Query)
* طراحی مدل ستاره‌ای (Star Schema) با جدول تاریخ شمسی/میلادی مشترک
* Measure های سفارشی برای میانگین‌ها، درصد انحراف از میانگین شخص، رتبه‌بندی، و شاخص‌های زمانی (سابقه، تولد نزدیک)
* نقشه‌ی جغرافیایی برای نمایش پراکندگی محل سکونت پرسنل
* طراحی KPI و Measureهای تحلیلی
* تحلیل‌های زمانی و جغرافیایی
